# Linssen Design 搭配图设计 · 使用说明

[打开网页](https://linssenstudio.github.io/freya-style/) · [English](README.en.md)

## 快速开始

1. 在左侧「排版」挑选模板。缩略图显示实际版式，可按风格搜索。
2. 切到「素材」，上传自己的图片。上传后会自动填入模板空图框；双击图框可以单独换图。
3. 在画布上拖动图层调整位置；双击文字修改文案。右侧可调整选中图层和画布。
4. 点击「导出」，选择清晰度，下载 PNG 图片。

## 常用功能

- **画布尺寸**：在右侧「画布设置」选择竖版、方形、故事、横版或海报尺寸，也可自定义宽高。
- **图片显示**：选中图框后，在右侧选择「完整显示」以保留整个主体，或「铺满裁切」以填满图框。铺满时可调放大和位置，也可按住 Shift 拖动图框中的图片。
- **撤销与微调**：用 ⌘/Ctrl + Z 撤销；方向键微调，按住 Shift 每次移动 10 像素。
- **保存作品**：「工程」可下载项目文件，之后可重新导入继续编辑。草稿也会自动存入当前浏览器，刷新时可恢复。

## 保存与隐私

GitHub Pages 版本无需登录，草稿仅保存在当前浏览器，不会跨设备同步。清理浏览器网站数据、使用无痕窗口或更换浏览器后，草稿可能无法恢复。请用「工程」定期下载备份。上传的图片用于当前浏览器中的排版，不会通过 GitHub Pages 上传到云端。

也可以从仓库下载 `index.html`，双击文件离线使用。联网字体不可用时会使用系统字体。

原有 [Netlify 版本](https://freya-pop-style.netlify.app/) 是单独的云端登录版本；两边的草稿不会自动互通，可通过「工程」文件转移作品。
