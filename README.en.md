# Linssen Design Collage Maker · User Guide

[Open the app](https://linssenstudio.github.io/freya-style/) · [简体中文](README.zh-CN.md)

## Get started

1. Choose a layout in the left **Templates / 排版** panel. Each thumbnail previews the actual layout; you can search by style.
2. Open **Assets / 素材** and upload your photos. They fill empty image frames in order. Double-click a frame to replace just that image.
3. Drag layers on the canvas to arrange them. Double-click text to edit it. Use the right panel to adjust the selected layer or canvas.
4. Select **Export / 导出**, choose a resolution, and download a PNG.

## Useful controls

- **Canvas size / 画布设置**: Choose portrait, square, story, landscape, or poster presets, or enter custom dimensions in the right panel.
- **Image fit / 图片显示**: Select a frame and use **Show full image / 完整显示** to keep the entire subject, or **Fill and crop / 铺满裁切** to fill the frame. In crop mode, adjust zoom and position, or hold Shift while dragging the image inside its frame.
- **Undo and nudging**: Press ⌘/Ctrl + Z to undo. Arrow keys nudge a layer; hold Shift to move it 10 pixels at a time.
- **Save a project / 工程**: Download a project file and import it later to keep editing. Drafts are also saved automatically in this browser and can be restored after a refresh.

## Storage and privacy

The GitHub Pages edition needs no account. Drafts remain in your current browser and do not sync between devices. Clearing site data, using a private window, or switching browsers may remove access to a draft. Download a project file regularly. Images you add are processed in your browser and are not uploaded to a GitHub Pages cloud service.

You can also download `index.html` from the repository and open it directly, including offline. System fonts are used if online fonts are unavailable.

The existing [Netlify edition](https://freya-pop-style.netlify.app/) is a separate cloud sign-in version. Move work between editions by exporting and importing a project file.
