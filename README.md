# Linssen Design 搭配图设计

[中文使用说明](README.zh-CN.md) · [English user guide](README.en.md)

在线使用 / Open online: https://linssenstudio.github.io/freya-style/

这是一个在浏览器中制作穿搭拼贴、灵感板和海报的设计工具。GitHub Pages 版本无需登录，作品草稿保存在当前浏览器中。请定期用「工程」导出文件备份。

Create outfit collages, mood boards, and posters in your browser. The GitHub Pages edition requires no sign-in. Drafts stay in this browser; export a project file regularly as a backup.

网页为单文件 `index.html`，也可下载后直接双击打开。The app is a single `index.html` file that can also be opened locally.
